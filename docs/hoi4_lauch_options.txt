Hearts of Iron 4 can be launched with a number of additional command line arguments (or launch options in Steam). Hearts of Iron 4 command line arguments cannot include spaces or hyphens, except for the hyphen at the start of each argument. Quotes cannot be used to get around this limitation. So if, for example, one wishes to use -start_save= to load a save on startup, the filename cannot include spaces or hyphens.

Argument	Description
-ai_view	
-allowoldsave
-allowoldsaves	Allows save games with older save game versions to be loaded with only a tooltip warning, instead of blocking them altogether. Especially useful for testing shortly after increasing the save game version, since recent save games will still be loadable and relevant.
-audiodebug	
-auto_run=TEXT	Executes the run TEXT console command when a game is started/loaded, allowing to execute more commands.
-autosave=INTERVAL	Overrides the autosave interval in the user's settings.txt file. Can be one of the following: NEVER, DAILY, WEEKLY, MONTHLY, HALFYEAR, YEARLY
-autosave_count=N	Overrides the debug_saves count in the user's settings.txt file. Specifies how many autosave files are kept before the oldest one is deleted when creating a new one.
-checksum	Computes and writes out the overall checksum and the checksum of each individual game data file to user directory's /Hearts of Iron IV/logs/system.log. Useful when trying to identify if there is a modification to a single file, or some other file that exists but shouldn't, throwing off the checksum and blocking multiplayer.
-crash_data_log	Collects data on errors based on crashes that occur with critical bugs and malfunctions. Including if a buggy mod is activated from the launcher.
-debug	Indicates that the game should be run in debug mode, enabling a variety of extra behavior to help with development or testing. Some of the features can be turned on from the game console using the debug console command.
-dump_script_doc	Creates the /Hearts of Iron IV/script_documentation.json file (which lists Effects, Triggers, Modifiers, and Game variables) in the game's folder instead of launching the game.
-gamelog	
-hands_off	Automatically starts a 1936 game as Flag of Haiti Haiti,[1] unpaused, running at maximum speed, with human AI turned on. Additional effects include enabling the AI testing, test logs, and view, disabling the end screen, and disabling frame smoothing.
-historical
-historical=no
-historical=yes	Forces the historical focus gameplay setting on or off. Only works in conjunction with any auto-start option, like -hands_off or -start_tag. The default value in game is -historical=yes, so only -historical=no has any real effect currently.
-human_ai	Turns human AI on, so that even the country that the player is controlling is managed by AI.
-logpostfix=TEXT	Prepends the provided text to the beginning of log file names. Useful when running multiple instances of the game on a single machine, such as for multiplayer testing.
-logprefix=TEXT	Appends the provided text to the end of log file names. Useful when running multiple instances of the game on a single machine, such as for multiplayer testing.
-noai	Turns off all AI in the game by default, equivalent to automatically applying the ai console command with the in-game console.
-nofilewatcher	Turns off the file watcher, which observes game folders and reloads databases or UI when files change. Off by default in Release, but is turned on by -debug.
-nolauncher	Skips the launcher and resumes the last game with the enabled mods listed in the user directory's /Hearts of Iron IV/dlc_load.json, usually the last enabled mods.
-start_minimized	Starts the application minimized to the taskbar. Only available in Debug and Release_D. Only implemented for Windows at the time of writing.
-start_save=TEXT	Skips the main menu and directly loads a save file (specified by file name but without the ".hoi4" extension).
-start_speed=N	Sets the initial speed of the game (0-4).
-start_tag=TAG	Skips the main menu and directly starts a 1936 game as the country specified by TAG.
