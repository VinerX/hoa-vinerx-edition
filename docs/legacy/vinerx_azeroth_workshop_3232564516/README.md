# VinerX's Azeroth Legacy Snapshot

Источник: `C:\SteamLibrary\steamapps\workshop\content\394360\3232564516`

Это архив текстовых наработок из старого сабмода VinerX's Azeroth. Каталог нужен как reference-only снимок для последующего ручного переноса идей и механик в актуальный HOA VinerX Edition.

Правила использования:
- Ничего из этого каталога не подключено к текущему моду автоматически.
- Файлы здесь нельзя переносить в игровой мод целыми директориями или wholesale-копированием.
- Старый сабмод был сделан под другую версию HOA/HOI4 и использовал опасную схему `replace_path`, поэтому содержимое нужно адаптировать по частям.
- В архив перенесены только текстовые файлы (`.txt`, `.yml`, `.gfx`, `.gui`, `.mod`, `.lua`). Бинарные ассеты (`.dds`, `.png`, `.psd`) намеренно не копировались в `HOA-dev`.
- Имена каталогов в `snapshot/` специально переименованы и нормализованы, чтобы валидатор и игровые инструменты не воспринимали архив как часть мода.

Что внутри:
- `snapshot/raw_common/` — идеи, решения, персонажи, модификаторы, units/equipment и прочий скрипт. Старые фокусы лежат в `snapshot/raw_common/focus_trees/`.
- `snapshot/raw_events/` — события по AMA, QUE, Third War и связанным сюжетам.
- `snapshot/raw_history/` — исторические настройки стран из старого сабмода.
- `snapshot/raw_interface/` — текстовые `.gfx` и `.gui` описания интерфейса.
- `snapshot/raw_localization/english/` — английская локализация старого сабмода.
- `snapshot/descriptor.mod` — исходный дескриптор сабмода для справки.
